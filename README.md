# climate-adapt

**Оценка климатических рисков для региональных планов адаптации** — программа подготовки суточных данных метеостанций (проверка, контроль качества, восстановление пропусков), расчёта показателей климатических рисков, районирования и построения карт.

Автор: Федоров Дмитрий Сергеевич, научный сотрудник отдела гидрометеорологии и экологии ФГБУ «СибНИГМИ».

Работает с данными любого числа регионов: каждый регион проверяется, очищается, анализируется и картируется отдельно. Для НСО и Омской области заданы критерии ОЯ/НЯ, для других регионов они создаются из шаблона и вводятся в интерфейсе. Границы сезонов (тёплый и холодный сезоны, летние месяцы, месяцы оценки засухи, пожароопасный сезон, отопительный год) задаются для каждого региона на вкладке «Данные». Модули оформления, кластеризации, статистических тестов и загрузки границ общие с программой климатического районирования ([climatezoning-sibnigmi.streamlit.app](https://climatezoning-sibnigmi.streamlit.app)); помесячные ряды после контроля качества выгружаются в её формат.

## Цепочка обработки

| Вкладка | Что делается |
| --- | --- |
| 1. Данные | Единая загрузка: файлы и архивы ZIP/RAR/7z (в т. ч. вложенные) в любом сочетании. Тип файлов определяется автоматически: файлы станционного формата TT, TX, RR, FM, TS, RS, RH, FR и справочники `index_*` (строки с `*****` и слитыми числами — по фиксированной ширине поля, раскладка RR — автоматически), суточные таблицы Excel/CSV со сложной шапкой (объединённые ячейки, значения «+12.3», «12,3», «<0.5», «/», «20 км», «0400 м»). Источники объединяются, для совпадающих станций и дат выполняется сверка. Справочник станций, границы сезонов по регионам, расшифровка обозначений. |
| 2. Проверка | Согласованность форматов (RR, FM, TT против TX, масштаб TS, Td ≤ T, RH > 100 %, класс 0 в FR), полнота по станциям и годам, пропуски по всей сети, значения вне физических пределов. |
| 3. Контроль качества | Проверки допустимости, внутренней, временной и пространственной согласованности (по ВМО-№ 100, раздел 3.3): пределы значений, Tмин ≤ Tмакс, Td ≤ T, ночь + день = сутки, неизменные значения, медиана по сети и сравнение с соседними станциями (робастная z-оценка по месяцам), типовые ошибки осадков и ветра (коды, массовые сбои, км/ч вместо м/с, лишняя цифра), Isolation Forest; периоды повышенной строгости. Категории: ошибочное / требует проверки / исправленное, полный журнал с пояснениями правил. |
| 4. Пропуски | Интерполяция коротких разрывов, регрессия по соседям, IDW, отношение к соседям (осадки, ветер), KNN, Random Forest. Метод выбирается по перекрёстной проверке на скрытых значениях (MAE, RMSE, R²). Сетевые пропуски и разрывы > 60 сут не заполняются. |
| 5. Показатели | ETCCDI; АЖ/СЖ, мороз, сильные осадки за 12 ч, продолжительный дождь, очень сильный снег по критериям УГМС; бездождные периоды и периоды без снегопада по градациям и сезонам; атмосферная засуха, суховеи; заморозки в воздухе и на почве; переходы через 0, 5, 10 °C, суммы > 10 °C, ГТК; ГСОП; ветер > 10, ≥ 15, ≥ 25 м/с; индекс жары NWS (RH по T и Td); пожарная опасность; Tмакс 0,95 обеспеченности, уровни раз в N лет (Гумбель), Пуассон для АЖ. Сводка по жаре в формате отчёта 2016 г. с полем для базовых значений. |
| 6. Тренды и периоды | Манн — Кендалл (поправка Хамеда — Рао), наклон Сена, Петтитт, сравнение периодов (Манн — Уитни, бутстреп). |
| 7. Районирование | k-средних, Уорд, GMM; выбор k по силуэту и ARI; PCA, дендрограмма (из climate-zoning). |
| 8. Карты | Схематическая (Тиссен / изолинии / точки), по административным районам (субъект выбирается из списка OpenStreetMap, районы загружаются по его идентификатору; или GeoJSON), физическая (рельеф Terrarium или свой GeoTIFF/ASC, реки и озёра Natural Earth или OSM, города), на растровой подложке (OpenTopoMap, Esri Physical/Topo/Relief, OSM), интерактивная (работает в браузере без пересчёта программы, сохраняется в HTML). Заливка обрезается точно по границе субъекта. Интерполяция: регрессионный кригинг (широта, долгота, высота), IDW, ближайшая станция; LOO-проверка. |
| 9. Экспорт | Таблицы `table_NN_*.xlsx` с десятичной запятой, рисунки PNG/PDF 300 dpi, суточные ряды с признаками качества и восстановления, файл для climate-zoning, параметры обработки. |

## Запуск

```
pip install -r requirements.txt
streamlit run app.py          # или run_app.bat
python run_pipeline.py <папка_или_zip> --out results [--stations coords.xlsx] [--dem]
```

Все пороги и критерии — в `params.py` (часть меняется в интерфейсе). Для Барабинска (29612) правило «делить завышенный ветер на 10 с 2018 г.» включается в разделе «Правила и пороги» вкладки 3.

RAR читается через libarchive (`libarchive-c`; на Streamlit Cloud ставится из `packages.txt`). Если на компьютере библиотеки нет, архив RAR можно перепаковать в ZIP.

Встроенные слои Natural Earth (`data/basemap`) работают без интернета; Overpass, тайлы рельефа и подложек нужен интернет, скачанное кешируется в `~/.climate_adapt_cache`. GDAL не требуется.

Сбои внешних сервисов (Overpass API, серверы тайлов) сообщаются отдельно с указанием причины, чтобы их не путать с ошибками программы или данных.
